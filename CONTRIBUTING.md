# Contribuindo / Contributing

## Português
1. Abra uma **issue** descrevendo o problema ou a proposta.
2. Aguarde o dono **aceitar** (rótulo `aceito` ou comentário).
3. Faça um **fork** e abra um PR citando a issue (`Closes #N`).
4. O CI de PR externo só roda depois da **aprovação do dono**; só o dono aprova e mescla. Ninguém tem escrita direta.

PR sem issue aceita pode ser fechado sem análise. Não coloque segredos nem dados pessoais em issues ou PRs.
Contribuições são licenciadas sob a licença do repositório.

## English
1. Open an **issue** describing the problem or proposal.
2. Wait for the owner to **accept** it (`aceito` label or a comment).
3. **Fork** and open a PR referencing the issue (`Closes #N`).
4. CI for external PRs only runs after the owner approves; only the owner approves and merges. Nobody has direct write access.

PRs without an accepted issue may be closed without review. Never include secrets or personal data in issues or PRs.
Contributions are licensed under the repository license.
